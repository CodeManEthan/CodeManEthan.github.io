## Overview

A desktop implementation of the classic War card game built with Python and Tkinter — scaled far past the two-player original. Play with 2–100 players and 1–100 decks, watch automated rounds play out at adjustable speed, and track results on a live leaderboard.

## Highlights

- **2–100 players, 1–100 decks** — the game engine handles epic multi-deck battles, not just the classic head-to-head.
- **Speed controls** — from slow, watchable rounds to instant resolution.
- **Live leaderboard** — scores and wins tracked in real time.
- **Cross-platform** — runs on Windows, Linux, and macOS; Windows users get a one-click installer built with PyInstaller so no Python setup is needed.
- **Built-in rules reference** — the full ruleset ships inside the app.
